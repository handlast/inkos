## Writing Craft Rules

- **Emotion**: Externalize through action — never write "he felt angry", write "he crushed the teacup"
- **Salt in soup**: Values conveyed through behavior, not slogans
- **Supporting cast**: Every side character has their own agenda. Protagonist wins by outsmarting smart people, not crushing fools
- **Five senses**: Wet shirt sticking to the back, hospital disinfectant smell, rain puddles at the bus stop
- **Concrete**: Don't write "a big city" — write "the back seat of a taxi stuck in traffic for forty minutes"
- **Sentence craft**: Avoid "although...however" / "nevertheless" / excessive "was". Use character reactions instead of transition words
- **Desire engine**: Create emotional gaps → reader anticipates release → release MUST exceed expectations. 70% satisfaction = failure
- **Character check**: Before every character action ask: Why? Does it match their profile? Would the reader find it jarring?
- **Dialogue**: Different characters speak differently — vocabulary, sentence length, verbal tics, dialect traces
- **Forbidden**: Info-dump character introductions / introducing 3+ new characters at once / "everyone gasped in unison"
- **Escalation**: Bad things stack — each layer worse than the last. Not one setback, but setback → worse setback → even worse
- **Cycle awareness**: If currently in build-up phase, lay new obstacles and information; if climax phase, write payoff that exceeds expectations; if aftermath phase, write consequences — who lost what, who gained what, how relationships changed
- **Post-climax impact**: After a climax, never jump straight to new build-up. The next 1-2 chapters must show change: costs paid, status shifted, new normal established
- **Expectation management**: Delay release when the reader craves it (to amplify payoff); deliver feedback immediately when the reader is about to lose patience
- **Information boundary**: What does this character know? What don't they know? What are they wrong about? Characters must act only on information they possess
- **Reader clarity**: Suspense may hide answers, not the front-stage scene. Within the first 150-300 words of every core scene, make legible who is present, where they are, what is happening, what the protagonist visibly wants, what blocks them, and what immediate cost failure carries. Deliver this through action, objects, pressure, reactions, and dialogue — never a lore dump

## Alliance & Asset Hard Constraints (must enforce)

- **Alliance state**: If character context cards show two factions at war or hostile, characters from those factions cannot suddenly cooperate, ally, or have friendly dialogue (unless the prose shows a clear ceasefire/surrender/negotiation event driving the state change)
- **Nominal vs actual**: If diplomatic relations have nominalState vs state separation, writer must follow actual state; nominal state only governs characters' surface behavior (e.g., feigned surrender)
- **Asset possession**: If character context cards show an asset as lost/destroyed/lent, the character cannot use it in prose (unless the prose shows a recovery/repair/return event)
- **Death constraint**: If alliance_state shows a character was assassinated or purged, or character_matrix shows status=dead, that character cannot appear or speak in prose (flashback/dream/narrative reference除外, must be clearly labeled)
- **Subfaction loyalty**: If a character belongs to a subfaction, their actions must align with that faction's stance; if parentFaction and subfaction have internal conflict, the character must show a stance choice in prose
- **Military forces**: If military_forces shows a faction has X troops, prose must match (no "hundred thousand army" when ledger says five thousand); low morale means no spirited charges; depleted supplies means no well-provisioned camps
- **Treasury**: If treasury_state shows a faction has X gold, prose spending cannot exceed it (mercenary hires/bounties/purchases must align); depleted grain means no lavish banquets
- **Territory**: If territory_control shows a city/region controlled by the enemy, characters cannot casually operate there (unless prose shows a recapture/infiltration event)
- **Battle log**: If battle_log records a battle outcome (e.g., decisive_defeat), prose cannot rewrite that result; the same battle cannot be re-fought (unless flashback/narrative reference)
- **Epoch**: If epoch_timeline shows the current era is "turmoil", prose cannot depict peaceful prosperity; era_mood prosperity/war/stability values must match prose tone
- **Naval forces**: If naval_forces shows a fleet destroyed (status=destroyed), prose cannot send it to sea
- **Dynasty tree**: If dynasty_tree shows a character dead or inheritance established, prose cannot violate this lineage
- **Relationship graph**: If relationship_graph shows two characters with very low trust or status=estranged, prose cannot depict sudden intimacy (unless an event drives relationship repair)
