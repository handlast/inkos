## Hook 兑现正例/反例速查

以下对照表展示各类 hook 的有效/无效兑现写法。advance/resolve 的兑现段必须贴近正例风格。

### 状态变化类（疼痛/伤势/能力）
| 反例（无效） | 正例（有效） | 要点 |
|---|---|---|
| 他感觉身体有些不对。 | 他按住左胸，呼吸卡在喉咙里，额角渗出冷汗。 | 具体动作 + 可观察反应 |
| 他想起了旧伤。 | 左手又不听使唤了，杯子从指缝滑下去摔碎。 | 具体后果 + 可观察变化 |
| 他的能力似乎变强了。 | 他随手一推，门板整块飞出去，砸在对面墙上裂成三截。 | 具体效果 + 感官细节 |

### 物件类（借条/钥匙/信件）
| 反例（无效） | 正例（有效） | 要点 |
|---|---|---|
| 他想起那张借条还在抽屉里。 | 他拉开抽屉，借条还在最底层，边角被虫蛀了几个洞。 | 动作 + 感官细节 |
| 那个东西很重要。 | 他把令牌翻过来，背面刻着一个他不认识的篆字。 | 具体名称 + 可观察细节 |

### 信息类（秘密/线索/真相）
| 反例（无效） | 正例（有效） | 要点 |
|---|---|---|
| 他隐约觉得事情没那么简单。 | 他盯着屏幕上的编号，手指停在键盘上没动——N-44，C-77 提过的那个。 | 具体信息 + 可观察反应 |
| 他发现了一个秘密。 | 信纸最后一行只有八个字，他读了三遍才放下。 | 信息内容 + 角色反应 |

### 关系类（结盟/背叛/信任）
| 反例（无效） | 正例（有效） | 要点 |
|---|---|---|
| 两人的关系更近了一步。 | 她把最后一块干粮掰成两半，递了一半给他。他接过去没说话。 | 动作传达信任 |
| 他决定相信她。 | 他把后背露给她，面朝门口，开始检查弹药。 | 行为展示信任 |
